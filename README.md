# Taller de Espacios Vectoriales Complejos

Este repositorio contiene los talleres con números complejos, desarrollados en Python usando el tipo `complex` y la librería NumPy. Cubre operaciones con vectores y matrices complejas, producto interno, norma, distancia, valores y vectores propios, matrices Hermitianas y Unitarias, producto tensor, y una introducción a números complejos con aplicaciones a fractales y modelado de circuitos cuánticos.

## Built With

* [NumPy](https://numpy.org/) - Librería usada para operaciones con vectores y matrices complejas
* [Matplotlib](https://matplotlib.org/) - Librería usada para graficar y visualizar fractales y transformaciones
* [Jupyter Notebook](https://jupyter.org/) - Entorno de desarrollo usado para los talleres

## Contenido

* **ComplexIntro.ipynb** - Introducción a números complejos: operaciones básicas, representación polar, notación de Euler, y fractales (Mandelbrot y Julia).
* **Complex_Vector_Matrix_Operations_with_NumPy.ipynb** - Operaciones con vectores y matrices complejas: suma, negación, escalar, transpuesta, conjugada, adjunta, producto de matrices, acción de matriz sobre vector.
* **TallerEsp.Vect-ProdInterno-VectoPropios.ipynb** - Producto interno, norma, distancia, valores propios y vectores propios.
* **TallerEsp.Vect-Hermitian-Unitary-Tensor-Circuits.ipynb** - Matrices Hermitianas, Unitarias, producto tensor, y modelado de circuitos cuánticos (Mach-Zehnder, Deutsch).
